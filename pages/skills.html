一、核心机制

血怒

获取

施展盾系技能获得1层血怒（最多3层，持续18秒）

效果

每层：受到的伤害降低3%，造成的伤害提高3%

消耗

施展刀系技能消耗1层血怒，回复2%气血

战狂（第三层奇穴）

触发

刀系技能消耗3层血怒时触发

效果

额外造成一次大伤害 + 敌方减疗30%（持续3秒）

盾立（第一层奇穴-镇关）

触发

施展盾系技能获得1秒盾立

效果

免控1秒 + 抵御1次伤害（PVP核心）

战狂良性循环

携带盾猛秘籍时，战狂触发会减少盾猛9秒CD。触发越多，盾猛CD越快，盾猛又减大招CD，大招送的3血怒又可以触发更多战狂，形成闭环：

战狂触发 → 盾猛CD -9秒 → 盾猛可用 → 大招CD -3秒 → 大招送3血怒 → 更多战狂

实战运用：闪1→大3→闪2连续两次战狂，直接减掉盾猛18秒CD（≈重置），后续可立即衔接盾猛1-2段继续控制链。

盾墙流派优势：因战狂触发频率更高（3次战狂），CD循环效果最明显。

控制机制（无界端通用）

控制等级

击倒（高级控制）> 眩晕（低级控制）

高级控制可覆盖低级控制，低级控制打在高级控制过程中不生效

控制减疗

定身、眩晕、击倒类控制自带50%减疗

与战狂减疗叠加 = 80%减疗（控制中吃战狂）

递减规则

同类控制（除击倒外）10秒内：

  • 第1次：正常持续时间
  • 第2次：持续时间减半
  • 第3次：不生效

💡 实战要点

  • 斩刀眩晕在盾猛击倒过程中不生效，击倒结束后可生效（但难无缝衔接）
  • 眩晕→击倒：可在眩晕未结束时释放，无缝衔接
  • 控制中战狂：控制自带50%减疗 + 战狂30% = 80%减疗，爆发关键

二、主动技能详解（8选4）

以下按盾系/刀系分类展示所有8个可选技能：

盾系技能

盾猛

盾系 CD 18秒
1段

20尺突进 + 击倒3秒 + 获得1层血怒 + 减绝招CD 3秒

2段

轻功沉默3秒 + 获得1层血怒

秘籍选择
  • 核心推荐：刀系技能每消耗一层血怒，降低本招式3秒调息
  • 不再使命中目标倒地，命中时将其击退并眩晕3秒

盾墙形态下有独立CD的盾猛1段，可额外获得1层血怒

盾飞

盾系|刀系 CD 15秒
1段

扔出盾牌形成盾阵 + 切换擎刀状态（增伤15%）+ 获得1层血怒

2段

收回盾牌 + 退出擎刀状态 + 敌方控制效果（眩晕或击退）

特殊机制
  • 擎刀状态：禁用盾系技能，普攻变为隐刀（10尺位移+20%减伤1秒）
  • 盾阵控制：敌方在盾阵内时，自身距离盾阵10尺内则眩晕敌方1秒，10尺外则击退敌方
  • 2段无公CD：盾飞2段收回盾牌后可立即使用其他技能（如盾墙）

2段无公CD，所以盾飞2段后可立即盾墙，避免擎刀状态下无法使用盾舞和独立盾猛

秘籍选择
  • 常规推荐：调息增加5秒，清除刀系招式调息时间
  • 内功沉默2秒（看情况可带）

盾墙

盾系 CD 35秒
1段

进入盾墙姿态（持续30秒）+ 获得1层血怒 + 减绝招CD 4秒

2段

提前结束盾墙姿态，根据剩余时间返还调息

盾墙姿态效果
  • 禁用刀系技能，移速降低60%，伤害降低50%，免控
  • 普攻替换为盾舞（盾系技能，使用获得1层血怒）
  • 可用独立CD的盾猛1段（额外减绝招CD 3秒 + 1层血怒）
秘籍选择
  • 常规推荐：盾墙姿态每被攻击3次，获得1秒盾立
  • 盾墙姿态期间，自身8尺范围内队友免控+减伤35%（带盾壁时可带）

盾壁

盾系 CD 30秒

获得气血值上限30%的护盾（持续4秒）+ 解控 + 护盾存在期间免控 + 获得1层血怒 + 减绝招CD 4秒

被封外缴械时不可释放

秘籍选择
  • 常规推荐：护盾化解伤害额外提高10%，持续时间延长1秒
  • 周围队友同时获得气血值最大值15%的护盾（带盾墙时可带）

断马催城

盾系 CD 20秒

6尺眩晕敌方5秒 + 驱散一个增益 + 获得1层血怒 + 减绝招CD 3秒

秘籍选择
  • 常规推荐：恢复自身气血最大值的20%
  • 被命中目标造成的伤害降低15%，持续5秒

刀系技能

闪刀

刀系 CD 10秒
1段

15尺位移伤害技能 + 消耗1层血怒（回血2%）

2段

对敌方造成持续流血（16秒）+ 消耗1层血怒（回血2%）

3层血怒时使用触发战狂：额外大伤害 + 减疗30%（3秒）

秘籍选择
  • 核心推荐：增伤15%，持续12秒
  • 命中流血目标回血5%

斩刀

刀系 CD 10秒

20尺位移伤害技能 + 击落下马 + 减速50%（3秒）+ 消耗1层血怒 + 减绝招CD 1秒

秘籍选择
  • 核心推荐：3秒眩晕，并使得下次施展刀系技能返还其调息时间
  • 附加流血，持续16秒

绝刀

刀系 CD 8秒

6尺伤害技能 + 目标气血值低于50%时伤害提高50% + 消耗1层血怒 + 减绝招CD 1秒

秘籍选择
  • 核心推荐：目标气血值低于50%时，伤害再额外提高50%
  • 目标每有一层流血，额外造成一次小伤害

三、奇穴选择（4层2选1）

第一层

血狱

会心提高5%，流血最高可叠加3层

镇关 推荐

施展盾系招式获得1秒盾立（免控1秒+抵御1次伤害）

PVP核心奇穴，提供稳定免控

第二层

睥睨 推荐

攻击气血值百分比低于自身的目标后，自身增伤10%，持续5秒

实战更容易触发

陷阵

每次添加流血，会心会效提高6%（持续15秒，最多叠加2层）

第三层

碎甲

血怒不再降低受到的伤害，伤害效果提升至5%，持续时间延长至25秒，刀系招式不再消耗血怒

战狂 推荐

刀系消耗3层血怒，额外造成一次大伤害，并使敌方减疗30%（持续3秒）

PVP核心奇穴，爆发+减疗

第四层（决定绝招）

矢尽兵穷

解锁绝招「矢尽兵穷」

阵云结晦 推荐

解锁绝招「阵云结晦」

多段封轻功+免控+增伤+额外血怒

💡 流派选择建议

  • 新手：推荐盾壁生存流，双解控容错高，先熟悉技能机制
  • 熟练后：可尝试盾墙爆发流，追求更高爆发
